Cohort-Dilution Trophy Forecaster v3 forecasts each Grand Theft Auto VI trophy's earn rate on Exophase one week after launch (2026-11-26 00:00 UTC) as five quantiles (5%, 25%, 50%, 75%, 95%), from the house's launch-night reads of the game's PlayStation 5 trophy page. It decomposes each earn rate into holders over players tracked, models Exophase's refresh-dilution between reads, and extrapolates the trend with decay toward the target. Pure Python 3.13 standard library, deterministic, offline — no network, no model calls.

## Run it

```sh
python3 main.py
```
